# Student Grade Calculator

## About
A simple Java console application that calculates a student's grade based on their marks.

## Technologies Used
- Java
- Core Java
- Scanner
- Conditional Statements (if-else)

## Features
- Accepts marks from the user
- Validates marks between 0 and 100
- Calculates grades based on marks
- Displays the result in the console

## Grade Criteria
- 90–100: Grade A
- 75–89: Grade B
- 60–74: Grade C
- 35–59: Grade D
- Below 35: Fail

## How to Run
1. Open the project in Eclipse.
2. Run `StudentGradeCalculator.java` as a Java Application.
3. Enter marks when prompted.
